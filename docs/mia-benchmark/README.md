# MIA Benchmark

This directory contains an evidence-first benchmark of MIA as a developer intelligence system.

## Lifecycle
Create -> Understand -> Grill -> Plan -> Execute -> Verify -> Review -> Ship -> Learn -> Personalize

## Scope
The benchmark uses real repositories, real architecture, repository history, CI configuration, tests, and GitHub evidence. It does not treat generated code or documentation claims as proof of successful execution.

## Repositories
- thesohamdatta/Mia
- thesohamdatta/Mia-Lens
- thesohamdatta/aura

## Evidence policy
Each result is classified as PASS, FAIL, BLOCKED, NOT RUN, or INCONCLUSIVE. Missing execution evidence is never converted into a pass.
