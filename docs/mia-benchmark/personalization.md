# Personalization

## Objective
Determine whether a second task improves because MIA retained and reused project-specific knowledge from the first task.

## Method
1. Run Task 1 with explicit project intent and record decisions/lessons.
2. Store only justified learnings.
3. Run Task 2 on the same repository without repeating those details.
4. Compare architecture decisions, repeated questions, mistakes, unnecessary edits, and plan quality.
