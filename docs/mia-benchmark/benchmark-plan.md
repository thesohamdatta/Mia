# Benchmark Plan

## Objective
Measure whether MIA can reliably move real developer work through understanding, grilling, planning, execution, verification, review, shipping, learning, and personalization.

## Evidence sources
Repository contents, commits, diffs, branches, pull requests, CI configuration and runs, tests, static inspection, and reproducible observations.

## Execution constraint
The current evaluation is GitHub-first. Local execution is not assumed. A check is PASS only when execution evidence exists.

## Procedure
1. Establish repository baseline.
2. Map current MIA lifecycle capabilities.
3. Select bounded real tasks across Mia, Mia-Lens, and Aura.
4. Run Create/Understand -> Grill -> Plan -> Execute -> Verify -> Review -> Ship -> Learn.
5. Run a second task to test personalization.
6. Record hard metrics only where observable.
7. Audit CI against current package scripts.
8. Publish evidence-backed findings without a single aggregate score.

## Quality scale
0 failed; 1 poor; 2 weak; 3 acceptable; 4 strong; 5 excellent.
