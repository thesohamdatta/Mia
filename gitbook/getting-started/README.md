# Getting started

MIA is developed with Bun and TypeScript. The repository is the supported starting point for trying the current implementation.

## Requirements

- Git
- [Bun](https://bun.sh/) compatible with the version pinned in the repository's `package.json`

## Next steps

1. Follow [Installation](installation.md).
2. Read [Your first workflow](first-workflow.md).
3. Use `mia --help` to inspect the command surface available in your installed version.
