# CLI reference

MIA's executable command list is defined in `core/skills/index.ts`. Use `mia --help` to inspect the installed command surface.

| Command | Purpose |
|---|---|
| `mia grill` | Clarify intent before non-trivial work |
| `mia plan` | Create an explicit implementation plan |
| `mia spec` | Shape intent into a project specification |
| `mia setup` | Install MIA agent skills for supported hosts |
| `mia review` | Advance work through verification and review |
| `mia health` | Run repository verification |
| `mia ship` | Check handoff readiness |
| `mia learn` | Store or retrieve project learnings |
| `mia retro` | Review activity and learnings |
| `mia memory` | Read or append long-term memory |
| `mia checkpoint` | Save or load working state |
| `mia vc` | Inspect and deliberately mutate Git state |

See [Skills](skills.md) for more on the skill model.
