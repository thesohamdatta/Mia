# MIA — Machine Intelligence Architecture

MIA is a local-first AI engineering CLI for making AI-assisted software work more coherent, explicit, and verifiable.

The working loop is:

```text
clarify → plan → specify → execute → review → ship → learn
```

The model can change; the engineering discipline around it should remain consistent.

## Design principles

- Clarity before implementation.
- Verification over confidence.
- Small interfaces with complexity behind them.
- Human control over consequential decisions.
- Local state and durable learning.

MIA is actively evolving. The repository is the source of truth for current behaviour.
